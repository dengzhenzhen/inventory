# Windows 使用指南（Inventory 进销存）

本指南面向店里实际使用软件的店主和店员。`Inventory.exe` 是单文件程序，**不需要安装 Python、Node.js 或数据库**，双击就能用。

程序只在本机运行，数据保存在本机硬盘上，不会自动上传到云端。

## 1. 运行前准备

- 系统要求：Windows 10 或 Windows 11，64 位
- 建议把 `Inventory.exe` 放在一个可以正常写入的文件夹，例如 `D:\Inventory`
- 不要直接放在 `C:\Program Files` 这类受保护目录，也不要直接在压缩包里双击运行
- 如果是从旧版本升级，请先按第 5 节备份数据，再替换 exe

## 2. 第一次启动

### 2.1 双击运行

双击 `Inventory.exe`。会出现一个黑色控制台窗口，稍等片刻，浏览器会自动打开：

```text
http://localhost:8000
```

第一次启动可能需要 10 到 30 秒，因为程序要先解压运行环境并创建数据库。请耐心等待，不要连续双击。

控制台窗口会显示访问日志，**使用期间请保持这个窗口打开**。关闭控制台窗口就等于停止服务，网页也会随之无法访问。

程序同一时间只允许运行一份。重复双击时，会直接打开浏览器，不会启动第二份服务。

### 2.2 出现 SmartScreen 提示

本期程序没有代码签名。第一次运行时，Windows 可能显示蓝色的“Windows 已保护你的电脑”。

处理方法：

1. 点击提示框里的 **更多信息**
2. 再点击 **仍要运行**

只有从可信来源拿到的 `Inventory.exe` 才这样操作。如果文件来自陌生链接，请先联系提供者确认。

### 2.3 防火墙提示

程序默认监听 `0.0.0.0:8000`，目的是让局域网里的手机和其他电脑也能访问，也正因如此，Windows 防火墙会在首次运行时询问是否允许联网。**必须允许**，否则手机、平板或其他电脑无法通过局域网访问。

操作要点：

- 勾选 **专用网络**
- 点击 **允许访问**
- 如果店里的网络被 Windows 识别为“公用网络”，也需要勾选 **公用网络**

如果当时点了“取消”，本机浏览器可能还能用，但局域网内其他设备将无法打开页面。补救方法：

1. 打开 **Windows 安全中心**
2. 进入 **防火墙和网络保护**
3. 点击 **允许应用通过防火墙**
4. 点击 **更改设置**，再点 **允许其他应用**
5. 选择 `Inventory.exe` 并添加，勾选专用网络和公用网络

## 3. 登录与局域网访问

默认账号：

```text
账号：admin
密码：admin123
```

第一次登录后，建议进入 **设置 → 账号设置** 修改密码。

### 3.1 本机访问

浏览器自动打开的 http://localhost:8000 就是本机地址。如果浏览器没有自动打开，手动在地址栏输入这个地址即可。

### 3.2 手机或店内其他电脑访问

手机、平板、收银电脑需要和运行程序的电脑连接同一个路由器或同一个 Wi-Fi，然后在浏览器输入：

```text
http://<本机IP>:8000
```

例如本机 IP 是 `192.168.1.23`，就访问：

```text
http://192.168.1.23:8000
```

查看本机 IP 的方法：

1. 在运行程序的电脑上按 `Win + R`，输入 `cmd`，回车
2. 在窗口里执行：

```powershell
ipconfig
```

3. 找到当前联网网卡的 **IPv4 地址**，通常是 `192.168.x.x` 或 `10.x.x.x`

注意：手机上的 `127.0.0.1` 指的是手机自己，不能用来访问电脑上的程序。路由器重启后 IP 可能变化，重新用 `ipconfig` 查看即可。

程序还开放了 `/docs` 等接口文档地址，仅供店内网络使用。不要把 8000 端口映射到公网，也不要把访问地址发给无关人员。

## 4. 数据存放在哪里

默认情况下，数据就在 exe 同一个文件夹里：

```text
Inventory.exe
config.ini
data\
  inventory.db
  inventory.db-wal
  inventory.db-shm
static\
  images\
```

各部分用途：

- `config.ini`：端口、账号默认值、密钥等配置
- `data\inventory.db`：商品、进货、销售、库存和账号数据
- `data\inventory.db-wal`、`inventory.db-shm`：数据库运行时的辅助文件，属于数据库的一部分，**不要删除**
- `static\images\`：上传的商品图片

### 4.1 文件夹不可写时

如果 exe 所在文件夹没有写入权限，例如放在 `C:\Program Files`、只读 U 盘或受保护目录，程序会自动改用用户目录：

```text
%LOCALAPPDATA%\Inventory\config.ini
%LOCALAPPDATA%\Inventory\data\inventory.db
%LOCALAPPDATA%\Inventory\static\images\
```

查看方法：按 `Win + R`，输入 `%LOCALAPPDATA%\Inventory`，回车。

如果第一次运行后 exe 旁边没有出现 `config.ini`，说明数据很可能已经写到上面的用户目录了。

注意：移动 exe 时，数据不会自动跟着走。如果想整体搬家，请把 `Inventory.exe`、`data\`、`static\` 和 `config.ini` 一起复制到新位置。

## 5. 备份与恢复

数据只存在本机，定期备份非常重要。建议至少每周备份一次，并把备份放到 U 盘、移动硬盘或云盘。

### 5.1 正确备份方法

1. **先关闭程序**，也就是关闭黑色控制台窗口，等待窗口消失
2. 找到数据所在目录，参考第 4 节
3. 把整个 `data\` 文件夹和整个 `static\images\` 文件夹复制到备份位置
4. 如果修改过端口或账号，建议把 `config.ini` 也一起复制
5. 备份文件夹按日期命名，例如 `Inventory-备份-2026-10-17`

### 5.2 关于 -wal 和 -shm

程序使用 SQLite 数据库。运行期间，最新数据可能暂时写在 `inventory.db-wal` 里，还没有合并进 `inventory.db`。

- 最稳妥的做法是先关闭程序再备份，这样数据库文件是完整的
- 如果必须在运行中复制，请把 `inventory.db`、`inventory.db-wal`、`inventory.db-shm` 三个文件一起复制
- 运行中复制仍可能得到不一致的备份，所以停机备份才是可靠做法

### 5.3 恢复备份

1. 关闭程序
2. 把备份里的 `data\` 和 `static\images\` 复制回原来的数据目录
3. 保持原来的文件夹结构，不要只复制单个数据库文件
4. 重新双击 `Inventory.exe`

### 5.4 升级程序

先按上面的方法备份，然后关闭程序，只用新的 `Inventory.exe` 替换旧文件。`data\`、`static\` 和 `config.ini` 保留不动，原有数据会继续使用。

## 6. 修改端口或账号

### 6.1 编辑 config.ini

1. 关闭程序
2. 找到 `config.ini`，右键选择“打开方式”，用记事本打开
3. 文件内容大致如下：

```ini
[app]
host = 0.0.0.0
port = 8000
secret_key = 一串自动生成的字符
default_username = admin
default_password = admin123
token_expire_minutes = 720
cors_origins = *
max_upload_mb = 5
```

4. 修改需要的项目，保存文件
5. 重新双击 `Inventory.exe`

改完端口后，访问地址也要跟着变。例如把 `port` 改成 `8001`，本机就访问 http://localhost:8001，局域网就访问 `http://<本机IP>:8001`。

常用配置说明：

- `host = 0.0.0.0`：允许局域网访问，建议保持默认
- `host = 127.0.0.1`：只允许本机访问，手机和其他电脑会连不上
- `port`：服务端口，必须是没有被其他程序占用的数字
- `secret_key`：用于登录凭证签名，不要发给别人，也不要随意修改。修改后所有已登录用户都需要重新登录

### 6.2 修改账号和密码

`config.ini` 里的 `default_username` 和 `default_password` 只在**第一次创建数据库**时生效。已经开始使用后，改这两项不会改变现有账号。

已有数据的情况下，修改密码请这样做：

1. 用当前账号登录
2. 进入 **设置 → 账号设置**
3. 填写原密码和新密码，点击保存

如果设置页里显示的数据库路径是 `backend/data/inventory.db`，那是开发环境的说明。exe 版请以本指南第 4 节的路径为准。

## 7. 停止程序

关闭黑色控制台窗口即可停止服务。也可以在控制台里按 `Ctrl+C`。

只关闭浏览器标签页不会停止程序，后台服务仍在运行。需要关机、搬动电脑或备份数据时，请先关闭控制台窗口。

如果窗口卡住无法关闭，可以在任务管理器中结束 `Inventory.exe`，但不要频繁这样做，以免正在写入的数据来不及保存。

## 8. 常见问题

**双击后浏览器没有打开**

先看控制台窗口是否还在。如果服务已经启动，手动打开浏览器访问 http://localhost:8000。如果控制台一闪而过或出现报错，请截图保存后联系维护人员。

**提示“端口 8000 被其他程序占用”**

说明 8000 端口已被别的软件使用。关闭占用端口的程序，或者按第 6 节把 `config.ini` 里的 `port` 改成 `8001` 等空闲端口，然后重启程序。

**手机或别的电脑打不开**

依次检查：

1. 两台设备是否连接同一个 Wi-Fi 或同一个路由器
2. 防火墙是否允许了 `Inventory.exe`，参考 2.3 节
3. 地址是否是 `http://<电脑IP>:8000`，不要用 `127.0.0.1`
4. `config.ini` 里的 `host` 是否为 `0.0.0.0`
5. 路由器是否开启了“访客网络隔离”或“AP 隔离”，开启时设备之间无法互访

**程序被杀毒软件删除或隔离**

从可信来源重新获取 `Inventory.exe`，确认无误后在杀毒软件中添加信任或排除项。不要为了运行程序长期关闭杀毒软件。

**数据找不到了**

先确认 exe 旁边有没有 `data\` 文件夹。如果没有，数据可能在 `%LOCALAPPDATA%\Inventory` 下，参考 4.1 节。也可能是 exe 被移动到了新位置，而数据仍留在旧文件夹。

**能不能不联网使用**

可以。程序只在本机和局域网内提供网页，不需要连接互联网。但同一局域网内的设备要访问时，需要防火墙放行。
